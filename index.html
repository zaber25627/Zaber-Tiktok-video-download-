Frequently Asked Questions

Quick answers to common questions.

How do I download a TikTok video or photo post?

Copy the link from TikTok, paste it into the box above, and press Analyze Link. For a video, choose an option and press the download button. For a photo post, every photo is shown in a gallery with its own download button, plus Download All and ZIP buttons when there is more than one photo.

What does "HD Without Watermark" mean?

It is the high-quality file that the lookup service returns for the video. It is offered only when the service actually provides it. If it is missing, you will see a message and nothing else is downloaded automatically. The service does not report the pixel resolution, so none is shown.

What if a photo post also has a video?

Some photo slideshows come with a playable video version. When the service returns one, it is offered separately from the photos. When it does not, only the original photos are offered. The page never turns photos into a video.

Why is my link not working?

The link must be a full TikTok link. Private, deleted, expired, age- or region-restricted posts (including Stories that have expired) and temporary problems with the third-party service can all cause the lookup to fail. The service also limits how fast requests can be sent, so wait a couple of seconds and try again.

Why are some download options unavailable?

Only the files returned by the underlying service for that specific post are shown. If a version, such as audio, HD, or a slideshow video, is not returned, it cannot be offered.

Why are some creator statistics missing?

This site shows only the data the lookup service returns. Follower counts, following counts, total likes, and biography are not part of that response, so they are not displayed rather than guessed.

Why did my download fail or open in a new tab?

Files are hosted by TikTok's content servers. If a server does not allow the page to read the file directly, the page hands the link to your browser instead, which may open it in a new tab. In that case save the file from the new tab. ZIP downloads need direct access to each photo, so they can fail for the same reason. Links also expire, so analyze the link again to get a fresh one.

Does the downloader work on mobile devices?

Yes. The site is built mobile-first and works in modern mobile browsers. Some mobile browsers open files in a new tab instead of saving them directly. If that happens, use the browser's share or download option.
